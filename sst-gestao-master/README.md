# SST Gestão • Chave Mestre

Aplicativo administrativo totalmente separado do SST Gestão de campo.

Funções:
- no primeiro acesso, se a Central ainda não possui usuários, cria o primeiro administrador;
- login exclusivo de administradores;
- criar e editar usuários;
- definir perfil Administrador ou Técnico SST;
- ativar e bloquear usuários;
- redefinir senha;
- liberar todas as empresas ou empresas específicas;
- visualizar empresas sincronizadas;
- usar a mesma Central Online independente do SST Gestão.

Este aplicativo não altera nem incorpora o projeto original Auditar.
