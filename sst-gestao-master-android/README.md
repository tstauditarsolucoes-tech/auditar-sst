# SST Gestão • Chave Mestre Android

Aplicativo Android independente do SST Gestão de campo.

No primeiro acesso, se a Central não possuir usuários, permite criar o primeiro administrador. Depois disso, somente administradores podem entrar para gerenciar usuários, perfis, senhas, bloqueios e empresas liberadas.

Package: br.com.sstgestao.master
Versão: 1.0.0
